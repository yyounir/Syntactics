Syntactics — LeetCode Mode

An AI interview-prep tool that walks you through any LeetCode problem using the UMPIRE framework — with generated visualizations of how the data structure actually moves.

The Unique Kernel

Not an AI that just solves LeetCode problems — an AI that teaches you how to think through one, using UMPIRE (Understand, Plan, Implement, Review, Evaluate), and generates a visualization of the data structure in motion — a recursion tree unfolding, pointers sweeping an array — for whatever problem you throw at it. The generality is the point: it's not a canned demo of one problem type.

The "oh, that's cool" beat: watching the visualization render for a problem the AI has never seen hardcoded — proof the generation is real, not scripted.

Who It's For

CS students who want to become software engineers at top companies but don't know what resources will actually teach them how to approach a coding interview problem — not just show them an answer. (The learner building this is one of them.)

Why This Matters to the Learner

Comes from their own frustration figuring out how to actually learn to approach interview problems, rather than copying solutions. Building it is also their vehicle for leveling up on backend development — new territory for them.

The POC Boundary

  • LeetCode Mode only — Syntax Mode and Guided Mode are not built this round
  • Input: LeetCode problem number OR pasted problem statement
  • Language selector for the response
  • Toggle: Guided (step-gated UMPIRE reveal) vs. Full Framework (all stages at once)
  • Response includes: UMPIRE breakdown, time/space complexity with reasoning, required concepts, and a generated data-structure visualization
  • Visualization must generalize across problem types (recursion, arrays, graphs, etc.)
